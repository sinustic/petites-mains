# Petites Mains

Petit jeu interactif en français pour les enfants à partir de 2 ans : toucher, trier, trouver, animaux, sports, compter, mémoire, ombres, lettres, chemins, puzzle, et un album d'autocollants. Voix de Charlotte.

**Jouer en ligne :** https://sinustic.github.io/petites-mains/

Le jeu tient dans un seul fichier (`index.html`), sons et voix compris. Il fonctionne sur tablette, téléphone et ordinateur, dans le navigateur.
